# Project Guidelines & AI Assistant Rules

## Mandatory Post-Change Workflow

Whenever any feature, perk, balance change, mechanic, bug fix, or update is implemented in this codebase, always follow these rules:

1. **Update Documentation (`README.md`)**
   - Keep [`README.md`](README.md) synchronized with all changes.
   - Update relevant perk catalogs, tables, stats, weapon balances, mechanics, and system architecture sections whenever modified.

2. **Git Commit & Push**
   - Stage and commit the modified files with a clear, descriptive commit message.
   - Push changes to the remote repository (`git push origin main` or execute `Push_To_GitHub.bat`).
